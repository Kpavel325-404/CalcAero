# CalcAero 1.3

Native scientific calculator for PSP with 26 languages, eight Aero-inspired
themes and a signed User Mode EBOOT.

## Changes

- First launch starts in English and offers all 26 languages; the choice is saved immediately.
- Five new themes: Windows XP Luna, Windows Vista Aero, Vaporwave, Night Retro and WebCore Math.
- Memory-conscious rendering and font/layout caching; no CPU overclock required.
- Retains exact fractions, complex numbers, graphs, matrices, calculus, units,
  a 64-bit programmer mode, history, Mini-CAS, exercises and exports.

## Install

Copy the included PSP folder to your console's storage. Keep EBOOT.PBP and
assets together. On an update, merge folders and retain your saves and reports.

## Verification

The project owner reports successful operation on official OFW 6.61 and on
6.61 ARK-5 5.1.0 cIPL. Separate physical tests for OFW 6.60 and every model
are not recorded. Original automated reports cover 25,415 numerical checks,
1,694 UI states and PPSSPP's PSP-1000/32 MiB model at 222 MHz.

Full source, license notices, interface previews and verification reports are included.
