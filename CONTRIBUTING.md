# Contributing to CalcAero

Useful contributions include native-speaker review of the catalogs in
`assets/locale`, reproducible mathematics bug reports and testing on real PSPs.

For a bug, include CalcAero version, PSP model, exact firmware, language/theme,
steps to reproduce, expected result and actual result. A screenshot or exported
report helps. Remove personal data before attaching saves or logs.

For source changes, describe the behavior being changed, keep PSP-1000's memory
budget and User Mode requirements in mind, and run the relevant checks from
BUILD.md. Document the checks performed and any remaining limits in your pull request.

Translations must preserve format arguments, placeholders and mathematical
notation. Confirm that the resulting text fits the 480×272 interface.

Preserve third-party license notices and distinguish emulator results from
physical hardware reports. Please contribute only material you may redistribute.
