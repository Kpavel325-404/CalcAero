# Owner-provided English captures — CalcAero 1.3

The owner supplied 18 BMP screen dumps on 10 October 2026 and asked to use
English screenshots on GitHub. Their headers identify CalcAero 1.3. The
supplied BMP bytes are preserved unchanged; filenames with the attachment's
`(1)` suffix are recorded in `screenshots.json` and normalized here.

The public PNGs are lossless 480×272 conversions. The theme gallery adds a
surrounding title and captions and pastes complete unmodified frames. It does
not crop, resize, retouch or remove in-app capture notifications.

The firmware for each individual screenshot was not supplied. The owner's
separate confirmation for OFW 6.61 and 6.61 ARK-5 5.1.0 cIPL remains in
[USER-1.3-OFW.md](../USER-1.3-OFW.md). These images do not add an independent
hardware test by the assistant.
