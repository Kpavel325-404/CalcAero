# Снимки пользователя: версия 1.2

Восемь исходных BMP 480×272 прочитаны и сохранены без изменений. Видны Aero Green, калькулятор, справка, страницы клавиатуры и режим программиста. Текст и кнопки читаются; основная геометрия помещается на экране. По статичным BMP нельзя проверить мерцание, частоту CPU, батарею или длительную стабильность. Пользователь отдельно сообщил о стабильности 1.2. Эти снимки не подтверждают физический запуск 1.3 или работу на OFW.
