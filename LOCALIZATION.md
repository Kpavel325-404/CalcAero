# Локализация CalcAero 1.3.1

Каждый из 28 языков содержит полный каталог из 535 строк. Английский — встроенный
исходный язык; русский перенесён из рабочей 1.2. Остальные переводы созданы
машинным переводом с ручным исправлением названий основных режимов, настроек,
численных форматов и математических терминов. Для казахского дополнительно
заменены неудачные машинные строки и исправлены основные инструкции и ошибки.
Переводы ещё не прошли полную вычитку
носителями всех 24 языков: грамматика длинной справки и редких сообщений может
нуждаться в исправлениях. Наличие каталога не означает профессиональную
лингвистическую сертификацию. Редактируемые JSON включены для дальнейшей вычитки.

Португальский добавлен в 1.3.1 с кодом `pt` и новым LANG_PT в конце списка.
Перевод подготовлен с помощью ИИ; используется преимущественно европейская
терминология (definições, ecrã, ficheiro, guardar). Это один общий каталог,
без отдельных вариантов pt-PT/pt-BR. Вычитка носителем ещё не подтверждена.
У прежних 26 языков сохранены коды и номера; JSON-конфигурации совместимы.
Меню показывает по 14 строк в каждой колонке; Português — пункт 27, Français — пункт 28.
В базовый шрифт включены необходимые португальские буквы и диакритика.

Каталог бинарный, ограничен 256 KiB, имеет CRC, упорядоченные хэши и проверенные
границы строк. Printf-параметры сохраняют исходные типы, размеры и порядок.
Форматирование дополнительно проверяет их во время выполнения. Неизвестная
строка использует английский исходный текст.

English отображается встроенным атласом; расширенная латиница, греческий и
кириллица — поднабором DejaVu. Arabic, Devanagari, CJK и Hangul — лицензированными
поднаборами Noto. Загружаются общий шрифт и только нужный дополнительный шрифт.
Хинди и арабские соединения формируются HarfBuzz, растеризация — FreeType.
Арабские текстовые фрагменты располагаются справа налево; формулы и числовые
поля сохраняют обычный порядок. Сложное произвольное редактирование смешанного
RTL/LTR текста не является функцией математического редактора.

Атлас T8 512×512 (256 KiB) общий для текста и кнопок. Кэш глифов фиксирован;
глифы, использованные текущим кадром, не вытесняются. Контуры и подготовленные
текстовые раскладки кэшируются; шрифты не читаются с карты при каждом кадре.
Границы экрана, отсутствие пропущенных требуемых глифов, меню, страницы справки
и учебные задания проверены для каждого языка.

Исходники каталогов: assets/locale/*.json. `tests/build_locale.py`
компилирует каталоги и создаёт поднаборы шрифтов. Уже скомпилированные ресурсы
включены: для обычной сборки PSP Python и модель перевода не нужны.
Модели и пакеты для машинного перевода в ZIP и приложение не включены.

Французский добавлен с кодом `fr` и LANG_FR после LANG_PT. Полный каталог
из 535 строк подготовлен с помощью ИИ; вычитка носителем ещё не подтверждена.
Акценты, ç и œ включены в базовый шрифт.
