# Замена скриншотов в уже созданном репозитории

Этот ZIP обновляет фотографии и документацию. В нём нет папки `.git` и нет
изменений исходников калькулятора или установленного EBOOT.PBP.

1. В GitHub Desktop выбери CalcAero и открой Repository → Show in Explorer.
2. В папке репозитория удали **только старую папку PREVIEW**: новая полностью
   заменяет её. Старые изображения остаются в Git-истории.
3. Распакуй содержимое ZIP в эту же папку, согласившись на замену README,
   SHA256SUMS.txt и VERIFY/README.md. Папку VERIFY целиком не удаляй.
4. В GitHub Desktop проверь список изменений. Заголовок коммита:
   `Use English PSP screenshots and refresh the theme gallery`
5. Нажми Commit to main, затем Push origin. Если репозиторий ещё не опубликован,
   сначала воспользуйся Publish repository.

После push на главной странице будут английские снимки, галерея восьми тем и
ссылка на все 18 кадров. Распаковка ZIP сама ничего на GitHub не загружает.
