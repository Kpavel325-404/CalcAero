# Проверки на физической PSP

Версия 1.2: пользователь сообщил о стабильной работе и предоставил восемь
BMP 480×272. Они сохранены в VERIFY/USER-1.2-BMP; это свидетельство 1.2.
Ниже — аппаратные сценарии для новой 1.3, которые ещё не подтверждены.

- Первый запуск без config.json: English и все 26 языков на экране.
- Выбор русского; выход через HOME; повторный запуск сразу на русском.
- Выбор арабского, хинди и китайского: соединения, диакритика, читаемость.
- Переключение всех восьми тем; сохранение темы после выхода.
- PSP-1000: штатные 222 MHz, OSK, 3 графика, матрицы, отчёты и сон/возврат.
- PSP Go: ef0: и карта; PSP Street: работа без сети.
- OFW 6.60/6.61: запуск подписанного EBOOT непосредственно из XMB.
- Преднамеренная ошибка записи на карте: сообщение и сохранение прежнего языка.

Приложение не меняет прошивку и CPU. Не нужно менять ARK, cIPL или FLASH0.ARK
для проверки калькулятора. Существующая история сохраняется при объединении
папок, если не удалять файлы данных.
