# Публикация CalcAero на GitHub

В ZIP уже есть настоящая папка `.git`, ветка `main`, начальный коммит и тег
`v1.3`. Ссылка на новый репозиторий ещё не задана; push не выполнялся.

1. Создай на GitHub новый **пустой** репозиторий. Предлагаемое имя: `CalcAero`.
   При создании не добавляй README, `.gitignore` или лицензию: они уже в пакете.
2. Распакуй ZIP. Открой Git Bash или терминал в папке `CalcAero`.
3. Запусти помощник, подставив адрес своего нового репозитория:

```sh
bash tools/push-github.sh https://github.com/OWNER/REPOSITORY
```

Помощник публикует `main` и `v1.3`; принудительный push не используется.
Авторизуй Git обычным способом, если он попросит вход. Не вставляй токены в URL.

Можно выполнить команды вручную:

```sh
git remote add origin https://github.com/OWNER/REPOSITORY
git push -u origin main
git push origin v1.3
```

Если репозиторий уже содержит коммиты, сначала проверь его историю и объедини
изменения. Не применяй `--force` для обхода сообщения об ошибке.

## Оформление

Описание: `Scientific calculator for PSP with 26 languages, 8 themes and a signed EBOOT.`

Темы репозитория: `psp`, `homebrew`, `calculator`, `c`, `aero`, `multilingual`.
Главная страница использует README.md и включённые снимки интерфейса.

## Release

Создай выпуск по тегу `v1.3`, название `CalcAero 1.3`, описание из
RELEASE-NOTES-1.3.md. Для пользователей прикрепи исходный установочный архив
`PSP-CalcAero-1.3.zip` или ZIP с папкой PSP; архив с `.git` предназначен для
публикации исходников, поэтому ему не нужно заменять установщик.

## Если загружать через браузер

Загружай обычные файлы проекта, **исключив `.git`**. GitHub создаст свою историю;
локальный начальный коммит и тег так не перенесутся. Git-помощник выше сохраняет
подготовленную историю. Эта инструкция сама ничего в GitHub не публикует.
